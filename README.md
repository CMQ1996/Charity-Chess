# Charity Chess

Charity Chess is a chess club dedicated to charitable pursuits while promoting the game of chess. The website is structured to provide information about the club in a readable and attractive way.

Users on this site will find it very interactive, with background images and clear, easy-to-read cover text. There is an activities section listing the ways we use chess to raise money for charities. There is also a signup page which brings the user to a fully functioning sign-up form. The contact section in the nav bar has the relevant address, email, and phone numbers.

![Screenshot from amiresponsive.co.uk](assets/images/amiresponsive.png)

## Features

### Navigation

The navbar is located at the top right of the page on large screens. There are four pages in the navigation section:

- **Home** — This is the landing page.
- **Our Activities** — This page lists all the charity events associated with chess that the club partakes in.
- **Sign Up** — This page is a form for users to fill out if they want to join our club.
- **Contact** — This page contains all the relevant contact information for the club.

## Deployment

The site was deployed to GitHub Pages. The steps to do so are as follows:

1. In the GitHub repository, navigate to **Settings**.
2. From the **Source** section dropdown, select **main** branch (or **master**, depending on your repo).
3. Once selected, GitHub provides a link to the completed site.
